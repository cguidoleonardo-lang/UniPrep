# 🎓 UniPrep — Dashboard de Preparación Universitaria

**UniPrep** es una aplicación web interactiva de página única (SPA) diseñada para ayudar a estudiantes egresados de secundaria a organizar su presupuesto, calendario de exámenes e itinerario de estudio antes del ingreso universitario.

---

## 🚀 Demo en Vivo

Puedes probar la aplicación desplegada en Vercel aquí:  
👉 **[https://uniprep-fawn.vercel.app/](https://uniprep-fawn.vercel.app/)**

---

## ✨ Funcionalidades Principales

* 💰 **Simulador de Presupuesto:** Calcula gastos acumulados por categoría (inscripción, materiales, transporte, etc.).
* 📅 **Cronograma de Exámenes:** Gestiona fechas, materias y sedes de examen clave.
* 📝 **Planificador semanal:** Itinerario de tareas completables de Lunes a Sábado.
* 💾 **Persistencia local:** Todos los datos se guardan en el navegador utilizando `localStorage`.
* 🌙 **Tema oscuro & Responsivo:** Interfaz adaptada a dispositivos móviles con estética slate/indigo/emerald.
